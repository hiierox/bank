# Сервис скоринга клиентов

Реализация сервиса, задачей которого является определение доступных продуктов для клиента, опираясь на его данные

## Основные функции

-   Принимает данные о клиенте (телефон, достаток и тд) и желаемые им продукты
-   Определяет количество баллов, исходя из которых происходит выбор доступных продуктов
-   Возвращает лучший продукт из желаемого либо отказ.
