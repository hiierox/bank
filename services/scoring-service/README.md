# scoring-service

Принимает заявку на скоринг (pioneer — с анкетой, repeater — по телефону и продуктам), вызывает antifraud-service, считает баллы и при одобрении отправляет результат в Kafka.

**Функции:** антифрод → расчёт баллов → выбор продукта или отказ; при одобрении — запись в топик `scoring_results`.

**Зависимости:** antifraud-service, data-service, Kafka.  
**Порт:** 8001.  
**Документация API:** `/docs`.

Подробнее по запуску и тестам — `CONTRIBUTING.md`.
