# Сервис для работы с данными клиентов

Реализация сервиса, задачей которого является добавление, обновление и возврат данных о клиенте используя базу данных (на данном этапе in-memory)

## Основные функции

-   Возврат по номеру телефона всех данных о клиенте 
-   Создание/обновление профиля
-   Добавление новой записи в историю
-   Обновление статуса существующего займа
-   Комбинированное обновление
