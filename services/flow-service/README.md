# flow-service

Определяет тип клиента (pioneer / repeater) по номеру телефона и возвращает список доступных продуктов.

**Функции:** запрос к data-service (есть ли пользователь) → 404 = pioneer, 200 = repeater; список продуктов из Redis (кэш) или конфига.

**Зависимости:** data-service, Redis.  
**Порт:** 8000.  
**Документация API:** `/docs`.

Подробнее по запуску и тестам — `CONTRIBUTING.md`.
