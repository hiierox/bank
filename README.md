# Сервис выбора флоу

Это временная реализация сервиса, задачей которого является определение типа клиента (новый или повторный) по номеру телефона.

## Основные функции

-   Принимает номер телефона клиента.
-   Определяет, является ли клиент новым (pioneer) или повторным (repeater).
-   Возвращает соответствующий тип флоу и список доступных продуктов.
