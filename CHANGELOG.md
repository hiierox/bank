# История изменений

## [0.7.0] - 2025-10-31

### Добавлено
- Переход user-data-service на персистентное хранилище - PostgreSQL

## [0.6.0] - 2025-10-26

### Добавлено
- Перевод сервисов с синхронного взаимодействия на асинхронное с помощью Kafka 

## [0.5.0] - 2025-10-24

### Добавлено
- Интеграция сервисов

## [0.4.0] - 2025-10-21

### Добавлено
- Сервис данных, in-memory
- Тесты для сервиса данных

## [0.3.0] - 2025-10-14

### Добавлено
- В сервис скоринга добавлен функционал проверки повторного клиента
- Добавлены тесты для всего нового функционала

## [0.2.0] - 2025-10-07

### Добавлено

-   Реализован Сервис скоринга.
-   Реализована бизнес-логика скоринга на основе правил подсчет баллов, немедленные отказы и выбор лучшего продукта.
-   Созданы все юнит-тесты и интеграционные тесты
-   Создан CICD пайплайн, который запускает ruff, mypy, pytest


## [0.1.0] - 2025-09-26

### Добавлено

-   Начальная структура проекта для сервиса `flow_selection`.
-   Эндпоинт `POST /api/products` для определения типа клиента и выдачи ему соответствующих продуктов.
-   Логика, определяюющая тип клиента: `pioneer` или `repeater`.
-   Валидация входящего номера телефона с помощью модели pydantic.
